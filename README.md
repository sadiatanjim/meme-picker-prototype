# meme-picker-prototype
A small, modular JavaScript project that lets users pick cat memes based on selected emotions. This project focuses on clean structure, semantic markup, and essential front-end concepts while keeping the UI simple and accessible.
## Features
* Emotion-based cat meme selection
* Dynamic rendering of images inside a modal
* Supports static images and GIFs
* Clean, modular code structure using ES modules (import/export)
* Fully semantic and accessible HTML layout

## What I Used
This project covers core front-end concepts, including:

### HTML
* Semantic structure for better accessibility
* Proper use of form inputs (radio buttons, checkboxes, select lists)
* Modal markup patterns

### JavaScript
* ES6 modules (import/export)
* Looping with for…of
* Selecting elements with:
    - querySelector()
    - getElementsByClassName()
* Working with DOM classes:
    - classList.add(), classList.remove()
* Array methods:
    - .filter() to create new arrays
    - .includes() for matching tags
* Showing/hiding modals dynamically
* Handling user interaction through events

### CSS
* Flexbox layout
* Responsive thumbnail grid
* Modal design with scrollable content
* Consistent styling and spacing
